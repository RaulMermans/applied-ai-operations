# Applied AI Operations

Mission: build the smallest reliable architecture for governed business workflows.

- Workflow before agent; deterministic controls surround model reasoning.
- Stay local-first: no deployment or premature framework commitment.
- AAO owns its contracts; frameworks are replaceable infrastructure.
- Keep one authoritative path, with no speculative abstractions or demo-only behavior.
- Inspect before editing, use bounded diffs, and keep docs aligned with code.
- Preserve mock/live distinctions and known-good checkpoints.
- Do not weaken tests or claim validation that did not occur.
